## 使用方法

1. 发送`#星铁开启版本推送`即可开启星铁版本检测推送
2. 发送`#星铁获取(预)下载链接`可获取星铁PC游戏的(预)下载链接

## 开发测试环境

> 测试版本更新后的消息推送，仅用于开发/测试，不建议在生产环境运行

请看WebApi项目[express](https://gitcode.com/rainbowwarmth/express)的文档说明

## 注意

· 原神从5.6版本开始不提供(预)下载的压缩包链接下载方式，此命令`#原神获取(预)下载链接`无法使用
